# 战斗机制

## 技能释放

- **SP**：当前 SP ≥ 技能的 SP 消耗才能释放，释放时扣除。SP 上限初始 50，随升级增长，最高 200。战斗中会缓慢回复 SP，每次 +1。
- **数量**：一个技能打出「数量」次，每次单独结算伤害或治疗。
- **准备时间 / 发射间隔**：第一发前等待「准备时间 + 发射间隔」，之后每发间隔「发射间隔」秒。
- **散布**：飞行物实际散布角度 = 散布角度 × 攻击散布系数（由特性提供，默认 1）。
- **附加状态**：攻击类技能命中后对目标施加；增益技能施加给自己。

## 伤害公式

每一段伤害单独计算：

1. 基础值 = (1 + 单次伤害/100) × 攻击属性 × 本系加成，向上取整
   - 攻击属性：物理 = 物攻，法术 = 魔攻，真实 = 物攻和魔攻中较高的
   - 本系加成：技能系别属于攻击者当前属性之一时 ×1.1
2. 克制后 = 基础值 × 克制倍率，向上取整；目标有两个属性时两个倍率相乘，见下方克制表
3. 最终伤害 = (克制后 − 0.8 × 防御) × 0.4，舍去小数，最少为 2
   - 防御：物理看物抗，法术看魔抗，真实伤害无视防御
4. 不致死技能：目标生命不会被打到最大生命的 10% 以下
5. 吸血：攻击者按最终伤害 × 吸血比例回复（见[天赋与特性](天赋与特性.md)）

治疗技能每次回复 单次伤害/100 × 攻击属性（向上取整）。

战斗中的六项属性 = 面板值 × (1 + 该属性所有增益之和)，向上取整。

## 状态

| 类型 | 举例 | 持续 / 触发 | 效果 |
|---|---|---|---|
| 增益 / 减益 | 吼叫、加速、麻痹、蛛网 | 按秒计时 | 对应属性按百分比增减 |
| 持续伤害 | 中毒、剧毒、点燃、流血、蒸汽 | 中招妖怪**每次行动**触发一次，按次数计 | 按最大生命百分比扣血，伤害类型见各状态说明，照常计算防御 |
| 控制 | 冰冻、眩晕 | 每次行动触发一次，按次数计 | 跳过本次行动 |
| 属性变化 | 淋湿 | 按秒计时 | 目标额外获得一个系别（淋湿 → 水），影响克制和本系加成 |
| 免疫 | 来自天赋 / 特性 | 战斗全程 | 对应名称的状态无法施加 |

- 状态带概率的，只有判定成功才会施加；没写概率的必定施加。
- 同名状态再次施加：可叠加的状态累加次数（或时间），不可叠加的只刷新。叠加上限：点燃 16、淋湿 16、中毒 16、剧毒 16、冰冻 8、恐惧 8、蒸汽 16、流血 16、麻痹 8、眩晕 8，其余不可叠加。
- 组合：点燃 + 淋湿 → 蒸汽（蒸汽：每次行动受6%最大生命的法术伤害，共3次，可叠加至16次），替换原状态。
- 「全部」免疫包括：中毒、剧毒、麻痹、速度、眩晕、点燃、冰冻、淋湿、恐惧。注意「速度」也包括己方加速类增益。
