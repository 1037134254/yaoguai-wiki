# 养成机制

## 属性计算

wiki 中的种族值与游戏图鉴一致（图鉴显示的是内部数值的 2 倍），计算属性时要先除以 2：

```
属性 = 向上取整[ (种族值 ÷ 2 + 个体值 + 取整(努力值 × 0.1)) × 0.01 × 等级 × 系数 × 10 ] + 2
```

- 系数：生命 1.5，物攻 1，魔攻 1，物抗 0.9，魔抗 0.9，速度 1
- 努力值 × 0.1 的取整：小数 .5 时取偶数（如 0.5→0、1.5→2），其余四舍五入
- 之后每个天赋 / 特性依次乘上对应倍率（「全属性」作用于六项），每次向上取整
- 战斗中再乘增益（见[战斗机制](战斗机制.md)）

## 个体值 / 努力值

- 个体值上限 16
- 努力值单项上限 99，六项总和上限 256
- 击败妖怪时，按对方的「击败奖励」属性获得努力值：对方该项种族值（图鉴数值）≥ 110 时 +2，否则 +1
- 果实 / 扁果直接加减对应努力值

## 天赋与特性

- **特性**：每只妖怪 1 个，从种族特性池按权重抽取，池里固定带一个「无」（权重 10）。各妖怪页列出了具体概率。
- **天赋**：妖怪个体身上的天赋，最多 4 个。
- 特性异草 / 特性仙草：都是把特性按特性池重新抽一次（仍可能抽到「无」）。当前特性是「无」且有异草时消耗异草，其余情况消耗仙草。
- 属性加成、攻击欲望、击退承受系数、状态免疫：特性和天赋都生效。
- 吸血、攻击散布、受击触发状态：只有作为特性时生效。
- 特性道具（史莱姆之心等）只能用在特性池里含该特性的妖怪身上。

## 进化

所有进化都要求等级达到条件等级：

- 等级进化：只看等级
- 道具进化：需要持有该道具，进化时消耗 1 个
- 天赋进化：需要拥有该天赋
- 同时满足时优先提示天赋进化

## 捕捉

```
捕捉值 = (葫芦捕捉力 + 30)² / (30 + 目标等级) × 0.016 × (1 − 目标血量比例 × 0.7)
```

能抓什么：

- 只能抓野外遭遇的妖怪。扔葫芦时自动选当前血量最低的那只
- NPC 对战（包括地图头目战）里对方的妖怪不能抓，会提示「那是别人的妖怪!」
- 秘境里的妖怪不能抓，会提示「这只秘境妖怪似乎只是往日的回影!」

葫芦会摇晃 3 次，每次都要通过一次「随机数 < 捕捉值」的判定，所以：

```
捕捉成功率 = 捕捉值³（捕捉值 ≥ 1 时必定成功）
```

例：木葫芦（捕捉力 20）抓 10 级、剩 10% 血的妖怪，捕捉值 ≈ 0.93，成功率 ≈ 80%；同一只满血时只有约 2.7%。各葫芦的捕捉力见[道具](道具.md#捕捉)。

仙金 / 太极 / 血炼葫芦抓到时还会额外加成：

- 仙金葫芦：随机 1 项个体值变为 16
- 太极葫芦：随机 1 项个体值变为 16，并获得天赋「闪光」
- 血炼葫芦：随机 1 项个体值变为 16，并获得天赋「妖王」（80%）或「头目」（20%）

## 野生妖怪

- 个体值：每项在 1~16 之间均匀随机
- 天赋数量：1 个 49%，2 个 30%，3 个 19%，4 个 2%（重复抽到同一个天赋时不叠加，实际可能更少）
- 每次抽天赋按等级权重：Lv0 每个 60，Lv1 每个 200，Lv2 每个 100，Lv3 每个 7，Lv4 每个 2。单次抽中某个 Lv1 天赋约 7.1%，Lv2 约 3.6%，Lv0 约 2.1%，头目 / 使徒 / 骑士约 0.25%，闪光 / 妖王约 0.07%
- 平均每只野怪带闪光或妖王的概率各约 0.12%（约 1/800），带头目约 0.43%
- 遭遇战约 3% 概率「遭遇可怕妖怪袭击」：敌人等级 ×1.2，个体值最低为 3
- 约 4% 概率「遭遇大群妖怪袭击」：敌人数量 ×3（最多 5 只）

## 妖怪蛋道具

- 天赋抽取用另一套权重：Lv3 每个 40、Lv4 每个 7，其余同上。单次抽中头目 / 使徒 / 骑士约 1.4%，闪光 / 妖王约 0.24%
- 闪光妖怪蛋额外加「闪光」，王者妖怪蛋额外加「妖王」，头目妖怪蛋额外加「头目」
- 未知妖怪蛋孵出随机种类
