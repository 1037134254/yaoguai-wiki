# 获取途径

各妖怪页也列出了自己的获取途径。

## 通用途径

- **初始妖怪**：[毛毛虫](妖怪/毛毛虫.md)、[萝卜兔](妖怪/萝卜兔.md)、[熊小子](妖怪/熊小子.md) 三选一
- **捕捉**：野外遭遇后用葫芦捕捉，成功率见[养成机制](养成机制.md#捕捉)
- **进化**：见[进化](进化.md)
- **孵蛋**：孩子是父方所在系列的最初形态，所以拥有某个系列的任意一只雄性，就能孵出该系列的第一阶
- **未知妖怪蛋**：在以下 9 种里随机孵出：[蝎小针](妖怪/蝎小针.md)、[玫玫](妖怪/玫玫.md)、[小鳄蛙](妖怪/小鳄蛙.md)、[毒毒蛙](妖怪/毒毒蛙.md)、[苏苏](妖怪/苏苏.md)、[毒毒蛇](妖怪/毒毒蛇.md)、[爬爬鳄](妖怪/爬爬鳄.md)、[夜玄猫](妖怪/夜玄猫.md)、[咪咪](妖怪/咪咪.md)

## 秘境

**秘境里的妖怪都不能捕捉**（扔葫芦会提示「这只秘境妖怪似乎只是往日的回影!」），只能通过秘境奖励的妖怪蛋获得。

秘境敌人等级随你的队伍变化：

```
敌人等级 = max( 队伍最高等级 + 敌人等级偏移 − 难度减值, 难度最低等级 )
```

| 简单 | 5 | 15 |
| 正常 | 0 | 30 |
| 困难 | 0 | 50 |
