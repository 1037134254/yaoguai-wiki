> 拥有土灵力的巨石蟒。

| 项目 | 值 |
|---|---|
| 编号 | 190 |
| 阶段 | 三阶 |
| 属性 | 岩石 |
| 蛋组 | 爬行 |
| 击退承受系数 | 0.5 |
| 击败奖励 | 魔攻努力值 +1 |

## 获取途径

- 野外：暴风山洞（Lv76~82）
- 进化：由 [岩怪蛇](../妖怪/岩怪蛇.md) 道具进化（Lv32 + 道具「土晶石」）

- 另见：秘境·Boss的试炼的敌人（秘境内无法捕捉）
